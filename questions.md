# Open questions — ai-project-template

Questions asked of the user that **block a ticket** and have not been answered. Ids are
`PRJ-Q<n>`, from the same sequence rules as tickets: mandatory, sequential, never reused.

An answered question moves to [questions_closed.md](questions_closed.md) with the answer, who
gave it, the date, and what changed as a result.

A ticket waiting on one of these carries `❓` in `TODO.md` and cites the question id. Everything
**not** blocked by a question keeps moving — see *Blocked on an answer is a status, not a stop*
in `CLAUDE.md`.

> **If it blocks nothing, it does not belong here.** A question with no dependent ticket is
> curiosity: ask it in conversation and let the answer land wherever it lands. This file exists
> so that work which cannot proceed is visible, not so that every uncertainty is archived.
